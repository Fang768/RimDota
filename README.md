# RimDota

RimDota 是一个面向 RimWorld 1.7 的 Dota 2 主题框架 Mod。它提供英雄隐藏标记、三维属性（力量/敏捷/智力）、Dota 属性栏、装备属性通道、物理/法术减伤、攻击/技能吸血和统一的 Dota 回血池；后续内容 Mod 可以在此基础上扩展英雄、技能和装备。

## 兼容性

- RimWorld 1.7（开发环境：1.7.4981 rev136 测试版）
- .NET 10（`net10.0`）
- 依赖 HarmonyRimWorld（`brrainz.harmony`）

## 当前功能

- 英雄框架：`DotaHero` 隐藏 Hediff 标记、`HediffComp_DotaHero`、`DotaHeroUtil` API。
- 三维属性：力量/敏捷/智力；获得英雄身份后通过原生风格窗口输入或调整初始三围、主属性和每级成长，成长步进为 0.1。
- 等级与经验：Dota2 1–30 级经验表，英雄击杀敌对 Pawn 或动物时按目标市场价值获得经验，升级时应用三围成长。
- 派生数值：
  - 力量：生命上限 +2%/点、回血 +0.1/点/秒
  - 敏捷：Dota 护甲 1/6 点/敏捷、攻击速度 +1 点/敏捷；Dota 总攻速限制为 20–500
  - 智力：法力上限 +5/点、回蓝 +0.05/点/秒、魔抗 +0.1%/点、心灵敏感度 +2%/点
- Dota 状态栏：圆形等级/经验徽章、法力比例条和可展开的六格装备；非征兆时可持久展开，征兆时自动展开。
- Dota 英雄页：为所有 Humanlike 种族自动注入页签，仅在英雄身上显示，包含完整属性和装备管理。
- 技能配置页：与属性、装备并列，包含 8 个天赋节点、7 格全属性加点、先天技能占位、3 个普通技能槽、2 个衍生技能槽和 1 个奥义槽。未锁定时可配置技能位置，重置/确认采用页面快照；确认后仍可升级技能等级。
- 技能池：通用技能池保存在存档级 GameComponent，小人专属技能池保存在英雄组件中。当前提供 6 个普通技能占位和 3 个奥义占位，统一 50 法力消耗、无实际效果。
- 底部技能栏：已配置并至少达到 1 级的技能会在小人底部 Gizmo 栏显示占位按钮，包含技能颜色、当前等级、最高等级和蓝耗；占位阶段点击会提示尚无实际施法效果。
- 成长资源：每个 Dota 等级获得 1 技能点，达到 XML 配置的 `skillPointCap`（当前 22）后停发；技能点同时用于技能等级和全属性加点。10/15/20/25 级和 27/28/29/30 级获得天赋点，25 级前每层只能选择一侧。
- 洗点药：提供物品定义但暂不提供制作配方；使用后重置技能配置、技能等级、属性点投入和天赋选择，并返还对应点数；保留英雄等级和经验。
- 属性概览：按 Dota2 结构显示攻击/防御双栏和三色属性块；攻击力拆分为基础攻击力和额外攻击力，移动速度使用 RimWorld 实际值，近战/远程闪避分别显示。
- 攻击速度：总攻速以 100 为基础，限制在 20–500；RimWorld 瞄准和攻击间隔乘以 `100 / 总攻速`，500 时为 5 倍攻速，20 时为 0.2 倍攻速。
- 装备：六格 Dota 装备栏（独立于 RimWorld 衣物系统），支持锁定装备并将其排除在自动合成之外；力量手套/敏捷便鞋/智力斗篷/力量腰带、32 件 Dota 2 基础组件，以及吸血面具 + 阔剑合成的疯狂面具。
- 装备描述：现有 Dota2 装备的机制说明保留，并追加 Dota2 中文维基对应的斜体背景描述。
- 装备操作：左键使用主动装备，按住拖动可移动到空格、与其他装备交换，拖出装备栏会丢下；右键保留锁定、解锁、丢下和查看信息菜单。
- 主动装备：支持法力消耗、同冷却组共享冷却和 Dota 式旋转冷却遮罩；快捷键接口已保留，当前不显示或绑定数字键。
- 自动合成：装备、解锁和读档后按槽位 1→6 选择最早完成的配方；同格完成时优先使用靠前的实际材料槽位，不依赖配方排序。
- 伤害系统：
  - 物理：Dota 护甲公式（不扣原版护甲穿透）
  - 法术：Dota 2 魔抗（基础 25% + 智力 0.1%/点 + 装备，正魔抗乘算）
  - 之后仍走原版护甲；通用减伤走 `IncomingDamageFactor`（加算、可为负）
  - 攻击/技能吸血按实际伤害结算，溅射不吸血
- 回血池：所有 Dota 回血统一入池，每 15 tick 结算，按伤口严重度降序分配。
- Mod 设置：“Dota 回复设置”中的生命回复平衡系数默认 `0.2`，只缩放实际生命回复结算，不改变装备描述或属性栏显示值，也不影响法力回复。
- 基础内容：月亮碎片、遗迹碎片/翡翠掉落和“遗迹科技”研究页；邪月祭坛位于独立的“遗迹建筑”分类，需要遗迹研究解锁，可作为工作台使用。
- 调试入口：Dev 模式 → 右键小人 → Pawns → 设为/移除 Dota 英雄、查看属性；技能页底部另有“升级”“升至满级”“洗点”三个开发者按钮。

## 构建

```powershell
dotnet build Source/RimDota.csproj
```

输出到 `Assemblies/RimDota.dll`（构建产物不入库）。

## 使用

1. 启用本 Mod 和 HarmonyRimWorld。
2. 建造邪月祭坛，或使用开发者工具直接给予英雄身份。
3. 选中非英雄殖民者并右键邪月祭坛，选择“献祭遗迹碎片”；小人会寻找可用的遗迹碎片并完成 5 秒献祭。
4. 英雄身份获得后点击“Dota 英雄属性未选择”警报，分配初始属性、主属性和成长。
5. 选中 Dota 英雄后右键地面上的 Dota 装备，装备会进入六格装备栏；非英雄不能装备。
6. “查看 Dota 英雄属性”会在 Player.log 输出等级、经验、属性、护甲、物理减伤、魔抗、吸血等。

## 已知限制

- 主动技能、实际技能效果、目标选择、技能冷却和技能施法尚未实现；当前技能占位只能配置与升级。
- Dota 基础/额外攻击力和远程闪避当前仅用于属性页显示，不参与实际战斗结算。
- 主动技能、攻击力、移动速度、攻击特效尚未实现；对应装备的属性留空并标注“待实现”。
- 条件型通用减伤（刚被兽被动、幽鬼折射等）只留接口。
- 真实伤害目前没有实际 DamageDef 映射。
- 属性图标仍为红/绿/蓝占位图；Dota 2 VTex 真图标尚未正式接入。
- 最新伤害/减伤/吸血系统尚未完成游戏内验证。
